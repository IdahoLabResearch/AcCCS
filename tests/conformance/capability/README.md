# Capability-tier testing — placeholder

This directory is intentionally empty.

**Capability-tier testing is out of scope for the conformance framework.**
Capability tests cover AcCCS's security-tool behavior — NMAP integration,
MIM forwarding, fault-injection probes — none of which exists in stable form
today.

This placeholder reserves the home for that future work so that, when it
arrives, it does not need to re-argue its place in the tree. Until then, no
tests live here.

See ADR-0003 (`docs/adr/0003-conformance-test-framework.md`), "Considered
Options → Capability tests in the same framework."
